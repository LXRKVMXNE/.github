# Contributing

Thank you for your interest in contributing!

## Flow

1. Fork the repository and create a feature branch
2. Make your changes
3. Verify locally (build / tests) before pushing
4. Commit with a clear message and open a Pull Request

## Notes

- Keep commits focused; describe the change clearly
- Follow the code style and conventions of the project you are contributing to
- For bug reports, include reproduction steps and environment details
- By participating, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md)
- Security issues: do not open public issues — see [Security Policy](SECURITY.md) for private reporting
