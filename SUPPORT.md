# Support

## Bug Reports & Feature Requests

Open an issue in the repository you are working with — template-guided forms are provided
(bug report / feature request). Please fill in the template so issues can be triaged faster.

## Security Issues

Do **not** open public issues for security vulnerabilities. See [Security Policy](SECURITY.md)
for private reporting instructions.

## Questions & Usage Help

- Read the project `README` (and `README_CN` for Chinese documentation) first
- Check existing issues for the same topic before opening a new one

## Response Expectations

Issues and reports are handled by the maintainer on a best-effort basis. Security reports are
prioritized per the [Security Policy](SECURITY.md) (acknowledgement within 72 hours).
