# .github

Account-level community health files. These files (issue templates, PR template, code of conduct,
contributing guide, security policy, support info, funding) apply as **defaults to all public
repositories** of this account that do not provide their own versions.

## Contents

| File / Directory            | Purpose                                                 |
| --------------------------- | ------------------------------------------------------- |
| `CODE_OF_CONDUCT.md`        | Contributor Covenant 2.1                                |
| `CONTRIBUTING.md`           | General contribution flow                               |
| `SECURITY.md`               | Security policy and private vulnerability reporting      |
| `SUPPORT.md`                | Where to get help                                       |
| `FUNDING.yml`               | Sponsor button configuration                            |
| `ISSUE_TEMPLATE/`           | Bug report & feature request templates + config         |
| `PULL_REQUEST_TEMPLATE.md`  | Pull request description template                       |

Projects that need project-specific versions should provide their own files, which take precedence
over these defaults.
